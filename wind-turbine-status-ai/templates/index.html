How the project works

From a raw Excel file to a live web application — the full machine-learning lifecycle.

1

Collect

160K+ ten-minute SCADA readings from two turbines, 80+ sensors each.

2

Clean

Remove empty and repeated header rows, fix data types, drop constant columns.

3

Transform

Create time features, encode the target, remove duplicate-information sensors.

4

Explore

Eight EDA charts reveal how wind, power and sensors differ by status.

5

Model

Four algorithms compared on a hold-out set using macro-F1 for imbalanced classes.

6

Deploy

Pipeline saved with joblib, served by Flask + Gunicorn on AWS.
