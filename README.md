# WindWatch AI – Wind Turbine Status Prediction

WindWatch AI is a machine learning project designed to predict wind turbine operating conditions and identify potential failures using data-driven analysis. It applies data preprocessing, feature engineering, and machine learning techniques to classify turbine status and support predictive maintenance.

The project includes an end-to-end machine learning workflow, from data preparation and model evaluation to deployment using Flask on AWS EC2, making the trained model accessible through a web application.

**Key Features:**
- Data preprocessing and exploratory data analysis (EDA)
- Feature engineering and machine learning model development
- Wind turbine status prediction
- Model deployment using Flask
- Cloud hosting on AWS EC2
- Web-based prediction interface

**Tech Stack:** Python, Pandas, NumPy, Scikit-learn, Flask, AWS EC2, Git, GitHub

**Objective:** To demonstrate how machine learning and cloud deployment can support wind turbine condition monitoring, improve maintenance planning, and reduce unexpected downtime.
